# Diagrams Directory (`diagrams/`)

## Purpose
This directory stores visual models, architectural blueprints, process sequence diagrams, data flow representations, and entity-relationship models using standard diagramming formats (such as Mermaid and PlantUML).

## Planned Diagrams
- `c4-context-and-container.md`: C4 model system context and container diagrams illustrating system boundaries, actors, legacy VFP systems, external tax authorities (SUNAT/OSE/PSE), and distribution targets.
- `mvc-modular-monolith.md`: High-level structural view of the modular monolith showing MVC layer separation, module boundaries, and internal dependencies.
- `hexagonal-target-architecture.md`: Target architecture diagram showing ports (driver/driven), adapters, core domain independence, and infrastructure pluggability.
- `migration-pipeline.md`: Process flow diagram detailing non-destructive data extraction from Visual FoxPro 9, transformation, validation, and loading into the new storage engine.
- `electronic-billing-flow.md`: Sequence diagrams for invoice generation, tax calculation, UBL XML generation, XSD validation, digital signing, and SUNAT dispatch.
