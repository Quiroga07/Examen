# Domain Model and Schemas Directory (`specs/domain/`)

## Purpose
This directory specifies the core business domain model, entities, value objects, domain invariants, Data Transfer Objects (DTOs), and contract schemas for ABC Software Corp.'s enterprise software modernization.

- [dtos-and-schemas.md](file:///c:/Users/LOQ/Documents/GitHub/Examen/specs/domain/dtos-and-schemas.md): Technology-agnostic data contracts, request/response DTOs, field-level validation schemas, and standardized error models.
