# Domain Model and Schemas Directory (`specs/domain/`)

## Purpose
This directory specifies the core business domain model, entities, value objects, domain events, domain validation rules, Data Transfer Objects (DTOs), and domain schemas for the modernized system.

## Planned Documents
- `domain-model.md`: Definitions of domain aggregates, entities (e.g., Product, WarehouseMovement, ElectronicInvoice, TaxDetail), and value objects (e.g., RucNumber, MonetaryAmount, TaxRate).
- `dtos-and-schemas.md`: Specification of contract DTOs for request/response payloads, internal module boundaries, and serialization schemas.
- `validation-rules.md`: Domain validation rules including tax precision, RUC verification checksums, and inventory balance invariants.
