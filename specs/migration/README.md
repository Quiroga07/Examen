# Legacy Migration Specifications Directory (`specs/migration/`)

## Purpose
This directory specifies the migration strategy, data preservation protocols, extraction/transformation plans, legacy inventory, and mapping frameworks for modernizing the legacy Visual FoxPro 9 system.

## Documents
- [legacy-data-inventory.md](file:///c:/Users/LOQ/Documents/GitHub/Examen/specs/migration/legacy-data-inventory.md): Formal inventory of known legacy concepts, technical unknowns (file extensions, code page, schemas), inspection protocols, and custodian artifact requests.
- [mapping-and-reconciliation.md](file:///c:/Users/LOQ/Documents/GitHub/Examen/specs/migration/mapping-and-reconciliation.md): Safe, non-destructive migration methodology detailing pre-migration hashing, read-only extraction, transformation, target ingestion, mathematical reconciliation proofs, error logging, and rollback planning.
