# Tax Compliance and SUNAT Specifications Directory (`specs/compliance/`)

## Purpose
This directory specifies Peruvian tax compliance standards, SUNAT catalog integrations, document status lifecycles, tax calculation algorithms (IGV, ISC, and other applicable levies), UBL 2.1 XML structure generation, XSD validation criteria, and the regulatory-to-UBL traceability matrix.

## Planned Documents
- `sunat-catalogs.md`: Catalog registry referencing official SUNAT codes (Catalogo No. 01 Document Types, No. 02 Currencies, No. 05 Tax Types, etc.).
- `tax-calculation-rules.md`: Mathematical formulas, rounding rules, tax base determination, and validation algorithms for IGV, ISC, and related taxes.
- `ubl-and-xsd-specifications.md`: Detailed XML specifications conforming to OASIS UBL 2.1 (Invoice, Credit Note, Debit Note, and Dispatch Advice / GRE) and SUNAT XSD schemas.
- `sunat-ubl-traceability-matrix.md`: Comprehensive traceability matrix mapping SUNAT regulatory requirements and legal fields to corresponding UBL 2.1 XML paths.
